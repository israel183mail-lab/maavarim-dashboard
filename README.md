# מעברים.נט — מערכת ניהול תכנית מעברים

מערכת ניהול לתכנית "מעברים" — ליווי תלמידים במעבר בין כיתה ח' לישיבה קטנה: ניהול תלמידים, מעקב השמה במוסדות, ציר משימות קבוצתי ופרטני, מדד סיכון, ו"רגע של מעבר".

## מצב הפרויקט

זהו **MVP עובד** שבנוי על בסיס האפיון (`meavarim_net_system_specification.pdf`) ומצגת העיצוב שסופקו. הוא ממש את כל 7 המסכים והלוגיקה התפעולית המרכזית מהאפיון. **לא ממומשות** בגרסה הזו יכולות ברמת-מכרז שתוארו במסמך ה-RFP המורחב: אימות דו-שלבי (2FA), יומן ביקורת (audit log) בלתי-ניתן-לשינוי, BI עם drill-down מתקדם, PWA/עבודה אופליין, ומנגנון אנטי-רמאות לקרדיטים. אלו מועמדות טבעיות להמשך פיתוח.

## מחסנית טכנולוגית

- **Next.js 15** (App Router) + TypeScript + React 19
- **Prisma** + **PostgreSQL**
- **Tailwind CSS** (פלטת הצבעים תואמת למצגת העיצוב: נייבי `#1D2445`, ירוק `#21B524`, כתום `#F7901E`, אדום `#FF3131`)
- אימות: JWT בעוגיית session (ללא ספריית auth חיצונית), `bcryptjs` לסיסמאות
- `recharts` לגרפים

## מסכי המערכת

| מסך | נתיב | תיאור |
| --- | --- | --- |
| דף הבית | `/home` | KPI-ים, "רגע של מעבר" וקרדיטים, פינת הודעות, רשימת מוסדות |
| דשבורד | `/dashboard` | תמונת מצב לרכזים/מנהלים, מדד אינטראקציות, מצב סיכון כללי |

| כרטיס תלמיד | `/students`, `/students/[id]` | חיפוש וכרטיס 360° עם גרף הצלחה, רשימת משימות, מסלול הכוון, יומן מעקב |

| אזור ניהול | `/admin` | טבלת כלל התלמידים, פרסום הודעות, ניהול משתמשים (מנהל כללי בלבד) |

## התקנה מקומית

דרוש Node.js 20+‎ ו-PostgreSQL מקומי או מרוחק.

```bash
npm install
cp .env.example .env   # ועדכן DATABASE_URL ו-AUTH_SECRET
npx prisma migrate dev --name init
npm run seed
npm run dev
```

## הרשאות (RBAC)

- **רכז/ת (COORDINATOR)** — רואה ומנהל רק את התלמידים שהוקצו לו.
- **מנהל/ת תוכנית (MANAGER)** — רואה ומנהל את כלל התלמידים והמוסדות, מאשר/דוחה "רגע של מעבר", מפרסם הודעות.
- **מנהל/ת כללי/ת (SUPER_ADMIN)** — כל הנ"ל, ובנוסף ניהול משתמשים (הוספה/הסרה, איפוס סיסמה).

## הערות על מודל הנתונים

- רשימות המשימות (ציר פרט/קבוצה) והמשקלים שלהן מוזנות ב-`prisma/seed.ts` בדיוק לפי הטבלאות באפיון (פרק 10–12).
- ציון ההצלחה מחושב לפי הנוסחה בפרק 13.3: `Success_Score = Task_Progress_Percentage * Risk_Multiplier`.
- כלל "לא ניתן לסמן משימה לפני קודמתה" (פרק 9) נאכף בצד השרת ב-`/api/students/[id]/tasks/[taskId]`.
